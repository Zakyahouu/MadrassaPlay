# MadrassaPlay Landing Page Assets

## Asset Structure

Place your assets in the `client/public/assets/` folder with the following naming convention:

### Screenshots (PNG format, 1920x1080 recommended)
- `asset-1.png` - Teacher Dashboard screenshot
- `asset-2.png` - Student playing game interface
- `asset-3.png` - Analytics dashboard view
- `asset-4.png` - Mobile app interface
- `asset-5.png` - Class management view
- `asset-6.png` - Parent portal interface

### Demo Videos (MP4 format, 1920x1080 recommended)
- `asset-7.mp4` - Gameplay demonstration video
- `asset-8.mp4` - Teacher workflow demo
- `asset-9.mp4` - Student experience demo

### Icons (SVG format, 64x64 recommended)
- `asset-10.svg` - Game icon
- `asset-11.svg` - Teacher icon
- `asset-12.svg` - Student icon
- `asset-13.svg` - Parent icon

## Asset Guidelines

### Screenshots
- **Resolution**: 1920x1080 or higher
- **Format**: PNG with transparency support
- **Quality**: High resolution, crisp text
- **Content**: Real platform screenshots showing actual features
- **Style**: Clean, professional, consistent with your brand

### Demo Videos
- **Resolution**: 1920x1080 or higher
- **Format**: MP4 (H.264 codec)
- **Duration**: 30-60 seconds per video
- **Content**: Screen recordings of actual platform usage
- **Audio**: Optional, but recommended for better engagement

### Icons
- **Format**: SVG for scalability
- **Size**: 64x64 pixels base size
- **Style**: Consistent with your design system
- **Colors**: Match your brand palette

## Implementation Notes

The landing page is already configured to use these assets. Once you add them to the `client/public/assets/` folder, they will automatically appear in the appropriate sections:

1. **Hero Section**: Live stats dashboard with real-time updates
2. **Features Section**: Interactive demo tabs with asset placeholders
3. **Screenshots Section**: Hover effects and live stats overlays
4. **3D Section**: Three.js integration with your 3D models
